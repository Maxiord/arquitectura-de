# Diagnóstico del entorno
este proyecto realiza un diagnostico basico de desarrollo utilizando node.js

## Información mostrada
version de node.js
plataforma
argumentos recibidos
una variable de entorno

## Ejecución con Node.js

Para ejecutar el programa directamente con Node.js:

node diagnostico.js prueba

## Ejecución con npm

Para ejecutar el programa mediante npm:

npm run diagnostico -- prueba

## Evidencia de ejecución

Versión de Node.js: v26.0.0

Plataforma: win32

Argumento recibido: prueba

Variable de entorno USERNAME: maxiv
